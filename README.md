# NutriKitchen

NutriKitchen is a personal nutrition and meal-planning application for tracking food intake, monitoring daily nutrition, and later planning meals from available ingredients.

## Current phase

The project is currently in the requirements and domain-modeling phase.

## Status

This repository intentionally starts with the project brief and domain design before Java implementation. The next implementation step is to model the identified entities in Spring Boot and add the first persistence and test layers.
